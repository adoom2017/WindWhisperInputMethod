# M5 本机验证

M5 将基线候选窗升级为原生 macOS 横排毛玻璃样式。竖排布局已评估并暂不纳入首版，避免同时维护两套尚未形成真实需求的交互；布局层保持独立，后续可以追加而不改输入内核。

## 已完成能力

- macOS 26 使用原生 `NSGlassEffectView` clear 玻璃与系统连续圆角；macOS 13—15 使用 `NSVisualEffectView` popover 材质回退。
- 48pt 高的紧凑候选窗：序号、正文、注释/辅码、页码与前后翻页入口；选中项使用浅强调色底、细描边与实色数字徽章。仅存在上一页或下一页时显示分页胶囊，单页候选不绘制也不预留分页空间。
- 超长正文和注释按可用宽度分别截断，面板最大宽度 760pt。
- 鼠标点击候选、点击翻页、滚轮/触控板翻页进入同一 Rime 状态流。
- 自动响应浅色/深色、降低透明度、增强对比度和减少动态效果。
- 首次出现使用 100ms 可中断淡入；输入更新和隐藏不等待动画。

## 自动化结果

运行：

```bash
./Scripts/test-m5.sh Debug
./Scripts/test-m5.sh Release
```

测试覆盖主题降级、横排边界、单页分页隐藏及空间回收、候选命中区域、短正文优先与长文本宽度分配、macOS 26 原生玻璃/旧系统材质回退参数，以及浅色/深色和普通/无障碍组合的离屏 PNG 渲染。M3/M4 回归继续分别由 `Scripts/test-m3.sh`、`Scripts/test-m4.sh` 覆盖。

## 本机视觉门禁

1. 在 TextEdit 中切换到“风语”，输入 `shi`，确认候选窗在插入点附近出现，整体为系统毛玻璃而非纯色矩形。
2. 候选应横向排列；高亮项、序号、候选正文、注释和页码均清楚，文字没有上下偏移或互相覆盖。
3. 连续输入与退格，确认候选窗宽度变化自然，没有明显闪烁、跳位或延迟输入。
4. 使用方向键、PageUp/PageDown、数字键、鼠标点击和滚轮/触控板翻页，确认视觉状态与实际提交一致，宿主输入焦点不丢失。
5. 切换 macOS 浅色/深色外观，确认背景、边框、高亮和文字都清晰。
6. 分别开启“降低透明度”“增强对比度”“减少动态效果”，确认背景转为清晰不透明样式、边界更明确、淡入被关闭。
7. 将窗口移到屏幕边缘和另一显示器，确认候选窗不越屏，Retina/缩放显示没有模糊或明显尺寸跳变。

以上通过后，M5 完成，可以进入 M6 词库、双拼与辅码阶段。
