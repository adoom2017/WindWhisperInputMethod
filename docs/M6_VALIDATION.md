# M6 验证记录

## 范围

M6 现交付风语全拼、自然码双拼、小鹤双拼（音形辅码与纯音码）、微软双拼、智能 ABC 双拼、基础词库、用户词频和独立辅码模式。数据来源、许可证、修改和更新方式已记录并锁定。

默认方案固定为“小鹤双拼（音形辅码）”；隔离用户目录首次创建 session 时状态必须为 `flypy` / `小鹤音形`。

## 固定语料

| 方案 | 输入 | 期望候选 |
|---|---|---|
| 小鹤双拼（音形辅码） | `nir` | `你` |
| 风语全拼 | `nihao` | `你好` |
| 自然码双拼 | `nihk` | `你好` |
| 小鹤双拼（纯音码） | `nihc` | `你好` |
| 微软双拼 | `nihk` | `你好` |
| 智能 ABC 双拼 | `nihk` | `你好` |

## 辅码验收

- 默认小鹤音形：`ni` 产生同音候选，补第一形码 `r` 后候选明显减少并包含“你”，完整码 `nirx` 自动上屏“你”。
- 原小鹤文本码表中的简码直接复用：单键 `k` 包含“可以”，双键 `aj` 包含“按键”，三键 `hvy` 包含“呼之欲出”。
- 四字词使用最多四键编码，`ahqi` 自动上屏“爱恨情仇”；生成器会在码表缺少简码或四字词时直接报错。
- 小鹤词典由用户原有四码单字表、简码和补充词表生成 36,253 条；测试会重新生成并逐字节比较。
- `;zuo` 返回 7 个本页候选并包含可见补码注释。
- 补仓颉首码 `k` 后，`;zuok` 缩小为 1 个候选“左”。
- 清空辅码组合后再次输入小鹤 `nihc`，仍返回“你好”，证明纯双拼路径未被辅码规则改写。
- 生成器输出 36,253 条记录；测试在临时目录重新生成并与随包文件逐字节比较。

## 原配置复用边界

- 可直接复用：`flypydz.dict.yaml`、`flypy_top.txt`、`flypy_sys.txt`、`flypy_user.txt`、`flypy_full.txt` 等 UTF-8 文本源文件，以及其中的简码、四字词编码和候选优先级。
- 不直接复用：原目录 `build/` 下的 `*.bin` 和 `*.userdb`。这些文件绑定原 librime 版本、部署签名和用户状态，风语会从文本源重新部署，避免 Apple Silicon 或升级后的兼容问题。
- 风语运行时不依赖 `/Users/shendongchun/Documents/rime-origin`；所需文本已复制进应用资源，原目录移动或删除不会影响已安装版本。

## 部署与升级保护

- 桥接层先读取已部署 schema 清单，拒绝切换到不存在的 schema ID。
- 桥接层监听 librime 部署通知；隔离副本中的 `default.yaml` 被故意破坏时返回明确失败，同时保留用户配置。
- 测试在部署前写入带哨兵的 `default.custom.yaml`，两次全量部署后内容完全一致。
- 测试选词触发 `luna_pinyin.userdb` 学习，销毁服务并再次全量部署后 userdb 仍存在。
- 所有测试使用 `/private/tmp` 的隔离目录，不接触正式风语或鼠须管用户数据。
