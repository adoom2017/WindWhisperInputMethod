# M4 本机验证

M4 已提供一个不抢焦点的基线候选窗。当前外观刻意保持简洁，原生毛玻璃、横排布局和视觉细节在 M5 完成。

## 自动化结果

运行：

```bash
./Scripts/test-m4.sh Debug
./Scripts/test-m4.sh Release
```

覆盖候选快照到展示模型、本页序号、鼠标命中、非激活面板约束、InputMethodKit 输入行矩形与 `firstRect` 回退、多显示器选择、上下翻转、屏幕边界、Rime 高亮、翻页和选择提交。M3 回归继续由 `Scripts/test-m3.sh` 覆盖。

## TextEdit 人工门禁

1. 打开 TextEdit 新文稿并切换到“风语”。
2. 输入 `shi`：候选窗应出现在插入点附近，显示页码、1—5 候选和首项高亮，TextEdit 光标仍保持激活。
3. 按向下/向上方向键：高亮应逐项移动；按 PageDown/PageUp：页码和候选应同步变化。
4. 按数字 `2`：应提交当前页第二项，候选窗随组合结束而消失。
5. 再输入 `shi`，用鼠标点击任一非首项：应提交被点击项；TextEdit 不应因为候选窗成为 key window而失去输入焦点，随后继续键入仍可直接输入。
6. 将 TextEdit 窗口移到屏幕底部、右侧和另一显示器重复输入：候选窗应向上翻转或向屏幕内收，不越出可见区域。
7. 在组合期间切换输入法或切换应用：候选窗必须立即消失，不跨应用残留。

若以上全部通过，M4 人工门禁完成，可以进入 M5 毛玻璃视觉阶段。
