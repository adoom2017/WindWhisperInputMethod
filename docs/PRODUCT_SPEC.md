# 首版产品规格

## 用户故事

- 用户可以在 macOS 系统设置中添加并切换到该输入法。
- 用户输入拼音或双拼后看到及时、清晰且不抢焦点的候选窗。
- 用户可以用数字、空格、回车、方向键、翻页键和鼠标完成选词。
- 用户可以按约定方式追加辅码以缩小候选范围。
- 用户可以切换中英文、简繁和输入方案，并在重启后保留选择。
- 用户可以在管理界面增删改、导入和导出自定义词，保存后立即生效；也可以打开用户目录和查看脱敏诊断。

## 首版交互范围

### 必须有

- 中文组合、marked text 与提交。
- 候选高亮、选择、翻页、取消。
- 全拼和经确认的双拼方案。
- 经确认的一种辅码体系。
- 插入点附近的毛玻璃候选窗。
- 深浅色、减少透明度和多显示器适配。
- 最小设置/状态入口和安全卸载说明。

### 可以后置

- 竖排候选布局。
- 皮肤市场和复杂主题编辑器。
- 在线更新词库、云同步和账号。
- 模糊音可视化编辑器。
- 表情、颜文字和预测插件。

## 默认键位（M3 基线已实现，候选交互待 M4）

| 操作 | 候选键位 |
|---|---|
| 首选上屏 | Space |
| 原始输入/确认 | Return（具体语义由 schema 与前端规则共同确定） |
| 取消组合 | Escape |
| 删除编码 | Backspace |
| 候选选择 | 1–9 或 schema 定义 |
| 高亮移动 | ↑/↓ 或 ←/→，随布局方向 |
| 翻页 | PageUp/PageDown、`-` 上翻、`=` 下翻 |
| 小鹤音形编码反查 | 输入音码后按 `~`，候选注释显示完整音形编码；可继续输入编码缩小范围 |
| 中英文切换 | 单按左/右 Shift 切换；Shift 组合键不误触；有组合时提交编码后切换 |

前端不得无条件覆盖 schema 的有效键位。M3 已确定 Command、Control、Option 组合默认交给宿主应用；前端只拦截经完整按下—释放且未参与其他按键的 Shift 单击，Caps Lock 仍交给系统/input engine。

## 视觉语义

- 候选窗应像 macOS 系统浮层，而不是独立应用窗口。
- 视觉焦点是当前高亮候选；辅助信息降低层级但仍满足可读性。
- 毛玻璃是增强，不是信息承载条件；关闭透明度后布局与层级仍成立。
- 动画只用于出现、消失和尺寸变化的连续性，不牺牲输入响应。

## 文案与诊断

- 错误信息说明发生了什么、是否影响输入、用户能做什么。
- 不向普通用户暴露裸 C 错误或内部路径；详细信息放入可复制的脱敏诊断。
- 保存自定义词后在后台重新读取用户词典，完成后无需重启输入法进程。
