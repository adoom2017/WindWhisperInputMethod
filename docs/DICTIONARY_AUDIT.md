# 词库合并审计

当前分支不再依赖外部词库工程或预编译词库文件。唯一权威资源是
`Resources/fy.dict.yaml`，每一行保留词条、编码、权重、来源和原始顺序。

## 排序规则

1. 完整编码和完整长句路径优先于未完成的前缀匹配。
2. 全拼与小鹤双拼纯音码的完整路径按词频、字符二元/三元连贯度和分词数量综合排序。
3. 小鹤音形仍按完整编码、权重和 `original-order` 排序。
4. 分数相同时保留词典顺序，保证结果可复现。
5. 同一词条在不同来源重复出现时只展示排序最前的一项。

## 运行时校验

- `InputService` 启动时解析词库并建立前缀索引。
- 资源缺失或格式无效会使引擎进入明确的不可用状态，不会静默读取其他目录。
- 应用包不包含原始分散词典、schema、预编译 bin 或外部动态库。
- 词库文件 SHA-256：
  `a673dc0591182a43e4339ce0bd836316361d265207ad22f4d82278d7f270cfe2`。

## iOS 词库生成

`Scripts/generate-ios-dictionary.sh` 调用 Swift 生成器，先将繁体词条转换为简体，
再按 iOS 字符白名单过滤。转换后的“词条、编码、来源”重复项按权重降序、原始顺序升序去重；
不同读音、编码和来源保留。最后保留四键以内的音形编码、拼音记录及权重至少 1,000 的词语记录。
生成器包含转换、去重、过滤、精简和幂等性回归校验。
