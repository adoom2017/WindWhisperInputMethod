# 词库合并审计

当前分支不再依赖外部词库工程或预编译词库文件。唯一权威资源是
`Resources/fy.dict.yaml`，每一行保留词条、编码、权重、来源和原始顺序。

## 排序规则

1. 完整编码优先于前缀匹配。
2. 权重较高的候选优先。
3. 权重相同时使用 `original-order`，保证结果可复现。
4. 同一词条在不同来源重复出现时只展示排序最前的一项。

## 运行时校验

- `InputService` 启动时解析词库并建立前缀索引。
- 资源缺失或格式无效会使引擎进入明确的不可用状态，不会静默读取其他目录。
- 应用包不包含原始分散词典、schema、预编译 bin 或外部动态库。
- 词库文件 SHA-256：
  `9166aa5dcc76560110485d1cece4fd04692aab37969c78fd7dc9633b5d043c02`。
