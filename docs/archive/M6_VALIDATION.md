# M6 验证记录

M6 验证风语词库合并后的候选覆盖和排序稳定性。

## 词库

- 应用只读取 `Resources/fy.dict.yaml`。
- 合并词库保留各来源的原始权重，并写入 `original-order` 列作为同权重候选的稳定排序依据。
- 小鹤音形、 小鹤纯音码和风语全拼共用同一份资源；Swift 引擎按编码类型构建对应索引。
- 用户词条写入 `custom_words.tsv`，以高于内置词库的权重参与候选排序。
- 在自定义词管理界面保存修改后，词条会在当前进程中自动生效。

## 结果

- 单字简码、完整四键、常用词组和辅码候选均通过固定语料验证。
- 相同编码的候选顺序与合并前权重规则一致。
- 四键唯一候选自动提交正常，多候选编码保留候选菜单。
- 重新创建服务不会覆盖用户词条，且不生成额外运行时词库文件。
