# AI Coding Agent 指南

## 开始前

1. 确认用户已明确允许开始编码，并确认当前获准里程碑。
2. 完整阅读 `DEVELOPMENT_PLAN.md`、架构、测试与决策文档。
3. 检查现有文件和版本控制状态，保留用户改动。
4. 列出本阶段要改的文件、测试和验收方式。

## 实施约束

- 一次只推进一个里程碑；先让最小闭环可验证。
- 不得跨过 `InputEngine` 从 UI 直接访问词库索引。
- 不得把候选窗逻辑、配置解析或词库加载堆入 InputController。
- 不得在按键处理路径执行配置刷新、磁盘扫描或网络请求。
- 不得记录用户明文输入，不得绕过 Secure Input。
- 不得未经许可安装输入法、修改系统输入源或删除用户数据。
- 第三方代码/词库进入工程前必须记录版本和许可证。

## 每次交付报告

报告必须包含：

- 完成了什么，以及与哪个里程碑对应。
- 修改的关键文件和架构影响。
- 实际运行的验证及结果。
- 没有运行或无法验证的项目。
- 新增决策、风险和下一步。

## 暂停条件

遇到以下情况必须停下来让用户决定：

- Bundle ID、产品命名、最低系统或分发范围不明确。
- 需要管理员权限、系统目录写入或切换用户当前输入源。
- 词库或代码许可证不清楚。
- 需要删除/迁移用户数据。
- 需求会扩大到联网、账号、遥测或自动更新。
- 现有用户改动与计划冲突且无法安全绕开。
